# 📦 DECLUTTER‑BY‑AREA PLAYBOOK  
*(All work is done in 30‑ to 60‑minute blocks.  The **staging zone** changes depending on which room you are working on, and **the sell‑rack can stay in the current staging zone** – NK‑room or Loft*  

---  

## 📖 DEFINITIONS  

| Term | Meaning |
|------|---------|
| **Staging zone** | A **single, temporary holding spot** depending on the room you are currently decluttering (upstairs staging area -> NK room or loft; downstairs staging area -> outside bins, garage for large items, loft for small items if needed). All items you have already sorted but that don’t yet have a permanent home stay **inside that zone**. |
| **Essentials** | Everyday‑use items you need while you’re decluttering that room.  • NK‑room → weekly‑clothes tote  • Guest‑room → shoe bin  • Loft → usually none |
| **Permanent location** | The final place where an item belongs (another closet, a shelf, the garage rack, etc.). If the spot is ready, put the item there immediately; otherwise leave it in the staging zone and **label the bin** with the intended destination (e.g., “→ Guest‑room closet”). |
| **Outside bins** | When the **only permanent home** is the **garage**, the item stays in a **labeled bin placed on a wheeled rack outside the back door** until the garage is ready. |
| **Donate box** | Must be a **large moving‑box‑size container**. **Seal it immediately** and **set it by the door or in the car** for donation run. |
| **Sell rack** | A **portable rack** that can stay **in the current staging zone** (NK‑room or Loft). Clothing you intend to sell goes on this rack; larger sell items that won’t fit in a bin stay in the garage, clearly labeled “SELL – [item] – Pending”. |

---  

## 🎨 COLOUR‑CODE LEGEND  

| Colour | Meaning | Where the bin lives |
|--------|---------|---------------------|
| **🟢 Green** | **Keep** – will end up in a permanent location. | Starts in the **staging zone** for the current room (or on the **outside rack** if the final home is the garage). |
| **🔵 Blue** | **Donate** – must be placed **immediately** into a **large box** (moving‑box size). | Box is sealed right away and **set by the door or in the car** for the next morning’s run. |
| **🟡 Yellow** | **Sell** – items you will list online. | Clothing → **sell‑rack** (kept in the current staging zone).  Large non‑clothing sell items → stay **in the garage**, clearly labeled “SELL – …”. |
| **🔴 Red** | **Trash / recycle** – immediate disposal. | Throw away right away; no bin needed after the session. |

## 📋 MASTER CHECKLIST

### Declutter‑By‑Area Quick‑Start (30‑60 min blocks)

#### NK‑Room (staging zone)
- [ ] Essentials tote – weekly clothes (label “DO NOT MOVE”)
- [ ] Pull & sort each item as you remove it:
    • 🟢 Keep → green bin on floor (label destination if not ready)
    • 🔵 Donate → large box, seal now, set by door or in car
    • 🟡 Sell (clothing) → place on NK‑room sell‑rack
    • 🟡 Sell (large) → leave in garage, label “SELL – Pending”
    • 🔴 Trash → discard
- [ ] If Keep item has a ready spot, place it there now
- [ ] Sweep/vacuum, close closet
- [ ] Seal donation box (date on side, keep by door/car)

#### Guest‑Room Closet 
- [ ] Essentials shoe bin (label “DO NOT MOVE”)
- [ ] Pull & sort each item (same 4‑step decision)
- [ ] Keep → green bin on floor (label destination) or place directly
- [ ] Sell (clothing) → place on Guest‑room sell‑rack (optional)
- [ ] Sweep/vacuum, close closet
- [ ] Trash
- [ ] Transfer donation box/es to door or car 
- [ ] Transfer green bins to NK-staging zone

#### Upstairs Main Closet 
- [ ] Pull & sort each item (same 4‑step decision)
- [ ] Keep → green bin on floor (label destination) or place directly
- [ ] Sell → place on upstairs sell‑rack (optional)
- [ ] Sweep/vacuum, close closet
- [ ] Trash
- [ ] Transfer donation box/es to door or car 
- [ ] Transfer green bins to NK-staging zone

#### Loft (fourth staging zone)
- [ ] Decide staging location (NK‑room floor or loft floor)
- [ ] Pull & sort each item (same 4‑step decision)
- [ ] Keep → green bin on chosen floor (label destination) or place directly
- [ ] Sell (clothing) → place on loft sell‑rack (you can use the same portable rack)
- [ ] Sweep/vacuum loft
- [ ] Trash
- [ ] Transfer donation box/es to door or car 
- [ ] Transfer green bins to NK‑room staging zone (if loft used)

#### Garage
- [ ] Set up wheeled rack by the back door (outside rack)
- [ ] Pull & sort items brought out (same 4‑step decision)
    • 🟢 Keep → labeled green bin **on the outside rack** (write final garage rack #)
    • 🔵 Donate → large box, seal now, set by door or in car
    • 🟡 Sell clothing → place on sell‑rack upstairs
    • 🟡 Large sell → leave in garage, label “SELL – Pending”
    • 🔴 Trash → discard
- [ ] Move outside racks inside when there is space
